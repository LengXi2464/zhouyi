# 易学入门 · 周易与传统术数基础知识学习与答题

一个可部署到 Cloudflare Pages 的中文互动学习网站，采用动漫女性化视觉风格，涵盖周易、五行、四柱八字、六爻、梅花易数五大板块，帮助用户系统学习中国传统哲学与术数文化知识。

## 一、功能概览

- **首页**：网站介绍、板块导航、今日学习进度、已掌握知识点数量、当前答题正确率。
- **基础知识**：按板块组织的知识学习，共 28 个知识模块，每模块含知识卡片、要点与配套练习题。
- **互动答题**：单选题与判断题，点击即判；正确显绿、错误显红并标出正确答案；每题附解析；作答后锁定，不可重复得分。
- **专项练习**：按板块筛选、按模块练习，支持随机打乱题序与选项。
- **综合答题**：全部 225 道题目混合练习，随机打乱；完成后显示成绩总结并列出答错的知识点；支持"只练错题"和"重新答题"。
- **错题本**：自动记录答错的题目；答对后自动移出；可手动移除；支持"只练错题"。
- **学习统计**：总览数据、整体正确率、各模块明细表；提供"清除学习记录"功能（二次确认）。
- **学习记录**：全部保存在浏览器 `localStorage`，刷新不丢失。

## 二、五大知识板块

### 1. 周易基础（10 模块 · 120 题）
周易概述、阴阳概念、爻与卦、八卦详解、六十四卦、上下卦与爻位、九与六、经与传、先天后天八卦、卦辞与爻辞基础。

### 2. 五行（5 模块 · 100 题）
五行基本概念、五行相生相克、五行与天干地支、五行旺衰、五行与方位颜色。

### 3. 四柱八字（5 模块 · 100 题）
天干地支基础、四柱构成、藏干与十神、排盘方法、四柱五行分析。

### 4. 六爻（4 模块 · 80 题）
六爻起卦、装卦与纳甲、爻位与用神、断卦基础。

### 5. 梅花易数（4 模块 · 80 题）
梅花易数概述、先天八卦数、取卦方法、体用关系。

## 三、题库说明

- 共 **480 道题**：单选题 **362 道**，判断题 **118 道**，覆盖 5 个板块、28 个知识模块。
- 每道题均提供答案与解析；题目以传统文化基础知识为主。
- 题库数据按板块拆分在 `src/data/sections/` 目录下，与页面逻辑解耦，便于维护与扩充。

题目数据结构：

```json
{
  "id": "zy-001",
  "section": "zhouyi",
  "module": "周易概述",
  "type": "single",
  "question": "题干",
  "options": ["选项A", "选项B", "选项C", "选项D"],
  "answer": 0,
  "explanation": "解析说明"
}
```

## 四、视觉风格

- **构建工具**：Vite 5
- **框架**：React 18 + React Router 6
- **语言**：原生 JavaScript（JSX）

## 六、本地运行

环境要求：Node.js ≥ 18。

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 3. 构建生产版本（输出到 dist 目录）
npm run build

# 4. 本地预览构建产物
npm run preview
```

## 七、部署到 Cloudflare Pages

### 方式 A：通过 Git 仓库连接（推荐）

1. 将本项目推送到 GitHub / GitLab 仓库。
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **创建应用程序** → **Pages** → **连接到 Git**。
3. 选择仓库后，按以下信息配置：
   - **构建命令**：`npm run build`
   - **构建输出目录**：`dist`
   - **环境变量**（可选）：`NODE_VERSION` = `18`（或更高）
4. 点击"保存并部署"。Cloudflare 会自动执行构建并发布。
5. 部署完成后，访问 Cloudflare 提供的 `*.pages.dev` 域名即可。

### 方式 B：使用 Wrangler CLI 直接上传

```bash
# 安装 wrangler
npm install -g wrangler

# 先构建
npm run build

# 上传 dist 目录
wrangler pages deploy dist --project-name yixue-rumen
```

### 关于子页面刷新 404

本项目使用 `BrowserRouter`（前端路由）。已在 `public/_redirects` 中配置：

```
/*    /index.html   200
```

该文件在构建时会被复制到 `dist` 根目录，Cloudflare Pages 会将所有未匹配静态资源的请求回退到 `index.html`，从而避免刷新子页面时出现 404。
